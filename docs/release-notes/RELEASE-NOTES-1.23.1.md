# ICL 1.23.1 Release Notes

## Summary

First release with GPG-signed RPM packages.

## Improvements

- RPM packages are now GPG-signed for verification with dnf/rpm.
- RPM repository metadata (repomd.xml) is signed.
- Public key available at https://atgreen.github.io/icl/rpm-repo/RPM-GPG-KEY-icl

## Breaking Changes

None.
